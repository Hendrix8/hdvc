# RaBitQ (Extended-RaBitQ only)

This folder now uses only `lib/Extended-RaBitQ` for RaBitQ experiments.

## Run BIGANN/SIFT1M

```bash
python -m rabitq.eval \
  --ext_root /home/cpanourg/projects/2-hdvc/lib/Extended-RaBitQ \
  --base_bvecs /data/cpanourg/2-hdvc/data/bigann/SIFT1M/bigann_base.bvecs \
  --query_bvecs /data/cpanourg/2-hdvc/data/bigann/SIFT1M/bigann_query.bvecs \
  --gt_ivecs /data/cpanourg/2-hdvc/data/sift/sift1m/sift_groundtruth.ivecs \
  --clusters 4096 \
  --bits 3 4 5 7 8 9
```

Outputs are generated by Extended-RaBitQ under:

- `lib/Extended-RaBitQ/results/exrabitq/bigann_exhaf*.csv`

Note: this implementation reports search metrics (`QPS`, `recall`, `ratio`) rather than the project's old ADC-vs-exact relative-error CSV schema.
